# Featured Projects

## ClearRun: Honesty Scoring for AI Responses
**Operations problem:** teams adopting AI need a control that flags when an answer sounds more certain than its reasoning supports.
Open TypeScript SDK + hosted API that scores whether an AI response's confidence is backed by its reasoning. **It does not fact-check.** A high score means confidence matches justification, not that the claim is true.
- `@clearrun/*` packages on npm at 0.1.0 · Hosted API: `https://api.clearrun.net`
- Open source: [Adepoco/ClearRun](https://github.com/Adepoco/ClearRun) · Release [v0.1.0](https://github.com/Adepoco/ClearRun/releases/tag/v0.1.0)

## BlastLoop: Structure-First Coding Framework for AI Agents
**Operations problem:** AI coding agents ship faster but fail faster. BlastLoop gives agent work a repeatable process with clear ownership and quality gates.
Blast / Mid / Inner programs write at their own altitude, then T1 structural, T2 bug/ops and T3 adversarial tests run in order.
- Repo: https://github.com/rlshaw-ml/BlastLoop
- Write-up: [WORLDWRIGHT Issue 3](https://worldwright.beehiiv.com/p/ai-did-not-remove-engineering-failure)

## Sovereign Job Hunter: Local AI Job Search Pipeline
**Operations problem:** job searching is a high-volume intake, triage and response workflow. This automates it end to end on your own machine.
Python pipeline that pulls job postings from Indeed RSS, scores each one 0 to 100 against a configurable profile using a local LLM, and drafts cover letters for top matches in your own writing voice. Runs fully locally.
- Repo: https://github.com/rlshaw-ml/sovereign-job-hunter
