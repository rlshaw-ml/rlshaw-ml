## ClearRun: Honesty Scoring for AI Responses

[![npm version](https://img.shields.io/npm/v/%40clearrun%2Fsdk)](https://www.npmjs.com/package/@clearrun/sdk)

**Operations problem:** teams adopting AI need a control that flags when an answer sounds more certain than its reasoning supports.
Open TypeScript SDK and hosted API that scores whether an AI response's confidence is backed by its reasoning. It does not fact-check. A high score means confidence matches justification, not that the claim is true.
`@clearrun/sdk` is 0.2.0 on npm. Hosted API: `https://api.clearrun.net`. [Adepoco/ClearRun](https://github.com/Adepoco/ClearRun) · [Release v0.1.0](https://github.com/Adepoco/ClearRun/releases/tag/v0.1.0)

## BlastLoop: Structure-First Coding Framework for AI Agents

[![GitHub stars](https://img.shields.io/github/stars/rlshaw-ml/BlastLoop)](https://github.com/rlshaw-ml/BlastLoop)

**Operations problem:** AI coding agents ship faster but fail faster. BlastLoop gives agent work a repeatable process with clear ownership and quality gates.
Blast / Mid / Inner programs write at their own altitude, then T1 structural, T2 bug/ops and T3 adversarial tests run in order. Launched Oct 2026. 32 GitHub stars and 1 fork.
[Repo](https://github.com/rlshaw-ml/BlastLoop) · [WORLDWRIGHT Issue 3](https://worldwright.beehiiv.com/p/ai-did-not-remove-engineering-failure)
